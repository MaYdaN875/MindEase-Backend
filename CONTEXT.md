 El proyecto consiste en el diseño y desarrollo de una aplicación móvil que permita conectar usuarios con psicólogos certificados para recibir apoyo psicológico mediante comunicación digital.

La aplicación tendrá dos tipos principales de servicios:


Consultas psicológicas de pago


Los usuarios podrán agendar consultas con psicólogos certificados dentro de la plataforma. Estas consultas podrán realizarse mediante chat o videollamada. La plataforma obtendrá ingresos mediante una comisión por cada consulta realizada.

Chat de apoyo gratuito


La aplicación también contará con espacios de chat gratuitos donde los usuarios podrán interactuar y recibir apoyo emocional moderado por profesionales o administradores.

El objetivo principal del proyecto es mejorar el acceso a servicios de salud mental mediante herramientas digitales accesibles, seguras y fáciles de utilizar.

Podría cumplir varias funciones útiles dentro del sistema.


1️⃣ Evaluación inicial del usuario (perfil emocional)

Cuando un usuario entra por primera vez, el chatbot puede hacer preguntas guiadas como:



¿Cómo te has sentido últimamente?


¿Has experimentado estrés o ansiedad recientemente?


¿Qué tipo de apoyo estás buscando?

Esto permitiría generar un perfil básico del usuario, por ejemplo:



ansiedad


estrés laboral


problemas de pareja


depresión leve


orientación general

Luego el sistema podría recomendar psicólogos especializados.

Esto se parece al proceso de triage psicológico.

2️⃣ Filtro previo antes de una consulta

El chatbot podría recopilar información para que el psicólogo ya tenga contexto:



motivo de consulta


nivel de urgencia


historial breve

Esto ahorra tiempo al profesional.
